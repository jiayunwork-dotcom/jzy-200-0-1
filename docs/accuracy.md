# 积分方法、精度与耗时

## 1. 被积函数

Paris 律（m 为材料固定指数，C 为可修正系数）：

```
da/dN = C · ΔK^m,        ΔK(a) = Δσ · √(π·a) · β(a/W)
```

- 中心穿透裂纹：物理（实测）长度 L=2a，β(a/W)=√(sec(πa/2W))；
- 边缘裂纹：物理长度 L=a，β(a/W)=1.12−0.231x+10.55x²−21.72x³+30.39x⁴（Tada 多项式，适用 a/W≤0.65，超出后冻结在 0.65）。

载荷谱由若干恒幅块组成，每块给应力幅 Δσ、最大应力和每天循环数。各块指数相同，故同一小区间内可合并为单一幂律：

```
da/day = w · a^(m/2),
w = C · π^(m/2) · β_mid^m · Σ_j (cyclesPerDay_j · Δσ_j^m)
```

## 2. 积分方式（按裂纹增量分步 + 解析分段）

不逐循环积分（四十余台起重机、数百万循环，逐循环无必要且慢），也不整条区间用单一解析式（β 随 a 变）。采用：

1. **按裂纹增量划小区间** [x1,x2]，区间中点冻结 β；
2. 每个小区间用 **解析原函数**：
   - m≠2：`N = (x2^(1−m/2) − x1^(1−m/2)) / (w·(1−m/2))`
   - m=2：`N = ln(x2/x1) / w`
3. **自适应中点对分**：把区间对分成两半，比较“整段一次”与“两半之和”。误差超限时递归细分（最大 60 层），并施加 Richardson 修正 `S + (S−S0)/15`（误差带按保守系数取 15）。

临界裂纹长度：在 [0,a_max] 上二分求 `K(a;σmax*)=KIC`（断裂）和直接解 `σmax*·W/lig(a)=σy`（净截面屈服），取先到者。最大应力取所有块的最大 σmax。

## 3. 精度（验收要求：恒幅例相对误差 ≤ 0.1%）

| 场景 | 结果 |
|---|---|
| 参考例（β≡1，Δσ=100 MPa，m=3，C=1e-11，a：1→10 mm） | 解析 N=7.7663×10⁵（题给 7.77×10⁵，差 0.05%）；数值积分器每个小区间就是解析原函数，机器精度 |
| 应力幅加倍 | N(2Δσ)/N(Δσ)=1/8（比值误差 <1e-12） |
| 有限宽边缘裂纹（β 随 a 变） | 与 20 万步细网格对比，相对误差 **1.6×10⁻⁸** |

默认相对容差 `DefaultTol=1e-8`，在全部验收用例上误差比 0.1% 的要求小 4 个数量级以上。

## 4. 耗时

- 基准（边缘裂纹，a：2 mm→临界 ~29 mm 全区间，默认容差）：
  `BenchmarkDaysToCriticalEdge` 实测 **约 0.67 ms/次，0 次堆分配**（arm64 便携环境）；
  常见的短间隔重算（裂纹尺寸区间更窄）在几十到几百微秒。
- 材料更新影响清单对该牌号所有部位各重算一次，O(部位数)；四十多台门机的规模为几十毫秒量级。
- 想要更快可把容差放宽到 1e-5（仍远优于 0.1%），当前默认取精度优先。

## 5. 设计边界

- 不模拟裂纹闭合/超载迟滞（块谱按线性 Miner 式累积）；这是与表格做法一致的工程近似。
- 边缘裂纹多项式在 a/W>0.65 冻结；该范围内裂纹通常早已被净截面屈服判为临界，计划中会给出临界根，属保守处理。
- ΔK 采用全应力幅 Δσ（即 σmax−σmin）。若现场习惯用半幅，录入载荷块时按全幅填写即可（系数 C 与幅的定义成对标定，修正会吸收系统性口径差异）。
